# iOS 图标与启动画面使用说明

## 文件清单

```
icons/ios/
├── app-icon-square-2048.jpg       # App 图标源文件（方形，用于 Xcode/iOS 打包，推荐使用）
├── app-icon-2048.jpg              # App 图标（带圆角展示版，用于 PWA / 安卓 / 预览）
├── splash-2048x2732.jpg           # 启动画面源文件（2048x2732，竖屏）
├── AppIcon.appiconset/
│   └── Contents.json              # Xcode AppIcon 配置模板
└── LaunchImage.launchimage/
    └── Contents.json              # Xcode 启动图配置模板
```

> **哪个图标用在哪里？**
> - **iOS 打包**：用 `app-icon-square-2048.jpg`（方形，iOS 会自动加圆角）
> - **Android 打包**：用 `app-icon-2048.jpg`（已带圆角，直接使用）
> - **PWA / 展示**：用 `app-icon-2048.jpg`（美观的圆角版本）

## 一、App 图标设置方法

iOS 需要多种尺寸的图标（iPhone/iPad/通知/设置等），最简单的方式是用一张 1024x1024 的源图自动生成所有尺寸。

### 方法 A：在线工具自动生成（推荐，最快）

1. 打开 [AppIcon.co](https://appicon.co/) 或 [MakeAppIcon](https://makeappicon.com/)
2. 上传 `app-icon-square-2048.jpg`（方形源图）
3. 选择 iOS 平台
4. 下载生成的图标包
5. 解压后找到 `AppIcon.appiconset` 文件夹
6. 在 Xcode 中打开项目，找到 `Assets.xcassets`
7. 删除原有的 `AppIcon`，把整个 `AppIcon.appiconset` 拖进去

### 方法 B：手动在 Xcode 中设置

1. 用预览或图片编辑器把 `app-icon-square-2048.jpg` 缩放到 1024x1024
2. 在 Xcode 中打开项目 → `Assets.xcassets` → `AppIcon`
3. 把 1024x1024 的图标拖到 **"App Store - 1024pt"** 那个框里
4. Xcode 会自动生成其他尺寸（Xcode 14+ 支持单尺寸图标）

> 注意：App Store 图标不能有透明通道（alpha），我们的 jpg 格式已经满足。

## 二、启动画面设置方法

### 方式一：使用 LaunchScreen.storyboard（推荐，适配所有屏幕）

Capacitor 创建的 iOS 项目默认使用 `LaunchScreen.storyboard`，这是苹果推荐的方式，可以自动适配所有 iOS 设备屏幕。

设置步骤：

1. 在 Xcode 中打开项目（`npx cap open ios`）
2. 左侧导航找到 `App` → `App` → `LaunchScreen.storyboard`
3. 点击 View Controller 中的 View
4. 在右侧属性检查器中设置背景色（取图标主色调 #5B5BF0 或渐变）
5. 拖入一个 ImageView 控件，设置内容为我们的图标
6. 添加居中约束（水平居中 + 垂直居中）
7. 设置宽高约束（如 200x200）
8. 也可以在下方加一个 "SpeakUp" 文字标签

### 方式二：使用启动图片（传统方式）

如果你想用生成的 `splash-2048x2732.jpg` 作为全屏启动图：

1. 在 Xcode 的 `Assets.xcassets` 中右键 → **New iOS Launch Image**
2. 把 `LaunchImage.launchimage` 文件夹拖进去（替换 Contents.json）
3. 在项目设置的 **General** → **App Icons and Launch Images** 中：
   - Launch Images Source 选择 LaunchImage
   - Launch Screen File 留空

> 注意：启动图片方式需要准备多种尺寸来适配不同设备，storyboard 方式更灵活，推荐使用。

## 三、Capacitor 启动画面插件（可选）

如果你想要更灵活的启动画面控制（比如自定义显示时长、添加动画），可以使用 `@capacitor/splash-screen` 插件：

```bash
npm install @capacitor/splash-screen
npx cap sync ios
```

在 `capacitor.config.json` 中配置：

```json
{
  "plugins": {
    "SplashScreen": {
      "launchShowDuration": 2000,
      "launchAutoHide": true,
      "backgroundColor": "#5B5BF0",
      "androidSplashResourceName": "splash",
      "androidScaleType": "CENTER_CROP",
      "showSpinner": false,
      "splashFullScreen": true,
      "splashImmersive": true
    }
  }
}
```

## 四、颜色参考

品牌主色（用于启动画面背景、UI 强调色等）：

- 渐变起始色（蓝紫）：`#7C5BFF` 到 `#5B5BF0`
- 渐变结束色（青绿）：`#00C9A7` 到 `#10B981`
- 图标主背景渐变：蓝紫 → 青绿

可以在 Xcode 中用这些颜色来统一 App 的视觉风格。

## 五、快速检查清单

打包上架前确认：

- [ ] App 图标已设置（所有尺寸）
- [ ] 启动画面已设置（storyboard 或 launch image）
- [ ] 图标没有圆角（iOS 会自动裁剪圆角，我们的图标已带圆角但作为全尺寸图使用时需要注意）
- [ ] App Store 图标（1024x1024）没有透明通道
- [ ] 启动画面适配所有设备方向
- [ ] 图标和启动画面在深色/浅色模式下都正常显示

> 提示：我们的图标本身带圆角效果，如果放入 Xcode 的 AppIcon 中，iOS 会再套一层圆角，可能会显得圆角过大。建议使用不带圆角的方形图标放入 Xcode，让 iOS 自动处理圆角。如果需要方形版本，可以告诉我重新生成。
